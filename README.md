# Где дешевле

Перенос приложения на React выполняется поэтапно. Экраны профиля, редактирования профиля, настроек и информации уже отображаются React; остальные экраны пока используют исходную логику в `public/legacy.js`. Исходные файлы сохранены в `original/`.

Для работы нужны Node.js (20.19+ или 22.12+) и npm или pnpm:

```sh
npm install
npm run dev
```

Для сборки: `npm run build`; результат находится в `dist/`. Проверить сборку локально можно командой `npm run preview`. Приложение следует открывать через HTTP-сервер, а не напрямую как файл.

Данные корзины, профиля и истории хранятся в localStorage браузера и сохраняются при использовании того же адреса сайта. Цены и часть данных магазинов демонстрационные.
