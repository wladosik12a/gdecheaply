# Статический каталог Mini App

Каталог и цены — снимок на 27 ноября 2026 года. Они обновляются только после нового экспорта и публикации; сведения о наличии по конкретному адресу не подтверждены. Карта использует онлайн-тайлы OpenStreetMap и онлайн-поиск адресов.

Чтобы обновить снимок, запустите Docker и API проекта gdecheaply-agent, затем в папке Mini App выполните:

```powershell
docker cp gdecheaply-agent-images-1:/data/product-images/. public/product-images
python scripts/export-static.py
npm run build
```

Скрипт читает локальную базу и публичную выдачу API, сохраняет выбранные поля товарных записей и не меняет базу. После проверки результатов изменения нужно отдельно сохранить в Git и опубликовать. Адрес Военная, 5 исключён по запросу пользователя.
